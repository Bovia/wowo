# 窝窝镇：以后的方向

窝窝以后想长成一个小镇：每个人的窝是镇上的一间，能串门，镇上有人在生活。

## 参考

- [Simile](https://www.simile.com/)：页面最下面那个俯视像素小镇。几个人自己在街上、广场上走，你只是看着，就觉得「这里有人在生活」。
  - 想要的是这种 **游戏感 / 有生活气** 的感觉，不是它的像素画风（窝窝目前是 3D 方块）。
  - 以后做窝窝的 **介绍网站** 时，可以照着它的结构来：上面讲是什么，最下面放一个能看、能逛的活小镇。

## 身份分三层

| 层 | 是什么 | 谁能看到 |
|---|---|---|
| 账号 | 登录用的邮箱 + 密码（以后可加手机号、微信） | 只有自己 |
| 居民 | 镇上的你：门牌号 `@xxx`、名字、捏的样子 | 所有人 |
| 家 | 属于居民的窝：户型、装修、家里人和猫、照片；库存永远只有自己能看 | 按可见范围 |

加登录方式只动「账号」；做小镇只是给「家」分地块；串门链接就是 `/@门牌号`。

## 已经做了（地基）

- `residents` 表：门牌号，跟账号分开
- `/@门牌号` 打开别人 **现在** 的家（旧的 `#visit=` 快照链接照样能开）
- 登录了去串门是自己捏的样子，没登录是中性的路人

## 以后再做

- 小镇地图和地块（`towns`、`plots`）
- 邻居 / 关注
- 足迹：谁来过我家、留言
- 镇上自己走动的居民。两个样板间可以先当最早的 NPC 邻居，解决刚开张没人的问题
- 画风待定：倾向保留 3D，从自家拉远镜头就是小镇，接上「缩小模式」
